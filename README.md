PlateAuction
1. Bài toán và phạm vi hệ thống

Hệ thống đấu giá biển số xe trực tuyến giúp người dùng đăng ký, tham gia đấu giá và quản lý phiên đấu giá một cách minh bạch.

2. Công nghệ sử dụng

Ngôn ngữ: Java   
Quản lý dự án: Maven   
Cơ sở dữ liệu: MySQL   
Giao diện: JavaFX    
Môi trường chạy: JDK 21+    

3. Cấu trúc dự án

PlateAuction/     
├── .github/          
├── .idea/        
├── src/          
├── gitignore          
├── DATABASE_MIGRATION.sql    
├── MIGRATION_TIMING_SYSTEM.sql      
└── pom.xml        

4. Câu lệnh dòng lệnh để chạy chương trình

Window:

chcp 65001; java -jar .\Auction-System-1.0-SNAPSHOT-standalone.jar

Linux/MacOS:

java -jar ./Auction-System-1.0-SNAPSHOT-standalone.jar

 
5. Cách chạy Server/Client
6. Danh sách chức năng đã hoàn thành 

[ ] Quản lý người dùng, sản phẩm

[ ] Chức năng đấu giá

[ ] Xử lý lỗi & ngoại lệ

[ ] Gia hạn phiên đấu giá khi bid cuối

[ ] Bid History Visualization: biểu đồ đường giá realtime (line chart)

[ ] Realtime Update
